# Go 1.27 Benchmark Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish deterministic Go 1.27 benchmarks for Threadfin's current parsing, filtering, serialization, segment-transfer, and cached-image behavior before any measured production optimization begins.

**Architecture:** Keep benchmarks beside the package they measure and construct deterministic fixtures before `testing.B.Loop`. Benchmark existing functions directly where possible; where current logic is trapped inside I/O-heavy handlers, first characterize the contract and then extract only a narrow behavior-neutral seam. The normal M3U benchmark is independent, while `BenchmarkM3UParsingLarge` is a separately gated task that is defined and captured only after a separately approved optimized-parser correctness repair. This foundation deliberately retains whole-buffer reads, `fmt.Sprintf`, `json.Unmarshal`, current XML marshaling, and current error ordering so later workstreams have an honest baseline.

**Tech Stack:** Go 1.27.0, `testing.B.Loop`, `testing`, `net/http/httptest`, `encoding/json`, `encoding/xml`, `bytes`, `io`, `golang.org/x/perf/cmd/benchstat`, GitHub Actions

**Spec:** `docs/superpowers/specs/2026-08-26-go-1.27-modernization-design.md`

## Global Constraints

- Target first-party Go code in the repository root and `src/`; exclude `vendor/`.
- Require Go `1.27.0` as declared by `go.mod`.
- Preserve Linux (`amd64`, `arm64`, `arm`), FreeBSD (`amd64`, `arm`), macOS (`amd64`, `arm64`), and Windows (`amd64`) support.
- Preserve external APIs, persisted formats, output ordering, JSON v1 compatibility, XML semantics, HTTP status/header behavior, and current error ordering.
- Do not introduce `strings.SplitSeq`, `base64.AppendEncode`, `encoding/json/v2`, streaming image/segment delivery, reusable XML encoders, or any other Workstream 3 or 4 optimization in this foundation.
- The current optimized parser returns zero streams for ordinary one-URL records; skip Task 1B and omit `BenchmarkM3UParsingLarge` from baseline execution until a separately approved correctness fix lands. Never remove its cardinality assertion or treat zero output as a benchmarkable compatibility contract.
- Extract a production seam only when current behavior cannot otherwise be benchmarked without unrelated server, network, or process setup; add characterization coverage before changing the production call site.
- Construct deterministic fixtures and reusable readers/writers before `for b.Loop()`; per-iteration reader and cache resets may occur inside the loop.
- Every benchmark calls `b.ReportAllocs()` and is run with `-benchmem`, reporting `ns/op`, `B/op`, and `allocs/op`.
- Collect ten before and ten after samples on the same machine and compare them with `benchstat`.
- CI compiles benchmarks but never gates merges on shared-runner timing variance.
- Do not add allocation thresholds until stable baselines exist.
- Keep each commit independently testable, reviewable, and easy to revert.

```go
package m3u

import (
	"bytes"
	"testing"

var benchmarkM3UResult []interface{}

const benchmarkM3UHeader = "#EXTM3U\n"

const benchmarkM3UFixedRecord = `#EXTINF:-1 tvg-id="channel" tvg-name="Benchmark Channel" tvg-logo="https://example.test/logo.png" group-title="Benchmark",Benchmark Channel
https://example.test/live/channel.ts
`

const benchmarkM3UTailPrefix = `#EXTINF:-1 tvg-id="tail" tvg-name="`
const benchmarkM3UTailSuffix = `" group-title="Benchmark",Tail Channel
https://example.test/live/tail.ts
`

func benchmarkM3UBySize(size int) []byte {
	minimum := len(benchmarkM3UHeader) + len(benchmarkM3UTailPrefix) + len(benchmarkM3UTailSuffix)
	if size < minimum {
		panic("benchmark M3U size is too small for one complete record")
	}

	fixedRecords := (size - minimum) / len(benchmarkM3UFixedRecord)
	padding := size - len(benchmarkM3UHeader) -
		fixedRecords*len(benchmarkM3UFixedRecord) -
		len(benchmarkM3UTailPrefix) - len(benchmarkM3UTailSuffix)

	var playlist bytes.Buffer
	playlist.Grow(size)
	playlist.WriteString(benchmarkM3UHeader)
	for range fixedRecords {
		playlist.WriteString(benchmarkM3UFixedRecord)
	}
	playlist.WriteString(benchmarkM3UTailPrefix)
	playlist.Write(bytes.Repeat([]byte{'x'}, padding))
	playlist.WriteString(benchmarkM3UTailSuffix)
	return playlist.Bytes()
}
```

```go
func BenchmarkM3UParsingNormal(b *testing.B) {
	cases := []struct {
		name string
		size int
	}{
		{name: "1MiB", size: 1 << 20},
		{name: "5MiB", size: 5 << 20},
		{name: "10MiB", size: 10 << 20},
	}

	for _, tc := range cases {
		b.Run(tc.name, func(b *testing.B) {
			input := benchmarkM3UBySize(tc.size)
			if len(input) != tc.size {
				b.Fatalf("fixture size = %d, want %d", len(input), tc.size)
			}
			streams, err := MakeInterfaceFromM3U(input)

			for b.Loop() {

				if err != nil {
					b.Fatal(err)
				}
				benchmarkM3UResult = streams
			}
		})
	}
```

```go
func TestHashPasswordPreservesExactPHCFields(t *testing.T) {
	hash, err := hashPassword("benchmark-password")
	if err != nil {
		t.Fatal(err)
	}

	parts := strings.Split(hash, "$")
	if len(parts) != 6 {
		t.Fatalf("PHC field count = %d, want 6: %q", len(parts), hash)
	}
	wantPrefix := []string{"", "argon2id", "v=19", "m=19456,t=2,p=1"}
	for i, want := range wantPrefix {
		if parts[i] != want {
			t.Fatalf("PHC field %d = %q, want %q", i, parts[i], want)
		}
	}
	salt, err := base64.RawStdEncoding.DecodeString(parts[4])
	if err != nil {
		t.Fatalf("decode salt: %v", err)
	}
	key, err := base64.RawStdEncoding.DecodeString(parts[5])
	if err != nil {
		t.Fatalf("decode key: %v", err)
	}
	if len(salt) != 16 || len(key) != int(passwordKeyLength) {
		t.Fatalf("decoded lengths = salt:%d key:%d, want salt:16 key:%d", len(salt), len(key), passwordKeyLength)
	}
	matches, legacy := verifyPassword("benchmark-password", hash)
	if !matches || legacy {
		t.Fatalf("verify generated hash = matches:%t legacy:%t, want true false", matches, legacy)
	}
}
```

```go
func benchmarkUpdaterJSON(prefix, suffix string, size int) []byte {
	padding := size - len(prefix) - len(suffix)
	if padding < 0 {

	result := make([]byte, 0, size)
	result = append(result, prefix...)
	result = append(result, bytes.Repeat([]byte{'u'}, padding)...)
	result = append(result, suffix...)
	return result
}
```
