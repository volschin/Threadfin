## Verified Current-State Contract and Scope

- `src/m3u.go:151-187` defines `checkConditions(streamValues, conditions, coType string) bool`; it normalizes `", "` and `" ,"`, eagerly calls `strings.Split(conditions, ",")`, iterates in order, and returns on the first match. Empty and repeated elements are observable because every string contains `""`.
- `src/internal/m3u-parser/xteve_m3uParser.go:114-123` eagerly splits on the literal substring `#EXTINF`, then unconditionally removes the first section with `channels[1:]`; lazy iteration must skip exactly one first yield even when empty.
- Benchmark-foundation Tasks 3-4 extract `serializeArgon2IDHash(salt, key []byte) string` in package `authentication` and isolate `BenchmarkArgon2HashSerialization` from `rand.Read` and `argon2.IDKey`. This plan changes only that extracted serializer after the foundation lands.
- Package name: `m3u`; module import path: `threadfin/src/internal/m3u-parser`.
- `src/internal/m3u-parser/xteve_m3uParser_optimized.go:195-202` dispatches inputs strictly larger than 10 MiB to `MakeInterfaceFromM3UOptimized`; inputs at or below 10 MiB use `makeInterfaceFromM3UOriginal`.
- `src/internal/m3u-parser/xteve_m3uParser.go:12-129` uses whole-input string replacement and splitting and has no line-size limit. This plan does not modify that normal parser.
- `src/internal/m3u-parser/xteve_m3uParser_optimized.go:35-36` configures the outer scanner with a 1 MiB maximum token buffer. The observed boundary is: a 1,048,575-byte logical line is accepted; a 1,048,576-byte logical line fails with `bufio.Scanner: token too long`, and the function returns `nil, err` even after earlier records were parsed.
- `src/internal/m3u-parser/xteve_m3uParser_optimized.go:104` creates a second scanner with the default `bufio.MaxScanTokenSize` limit. After the prerequisite correctness fix, a metadata or URL token of 65,536 bytes or more is silently dropped as an invalid record, while 65,535 bytes is accepted. Removing the rescan must preserve this implicit boundary explicitly.
- `bufio.ScanLines` already removes `\n` and an optional preceding `\r`, yields a final unterminated line, skips only zero-length lines in the outer parser, and therefore treats a whitespace-only line as the record URL. `strings.TrimSpace` then stores that URL as an empty string and the following actual URL is ignored. This malformed-input behavior is intentionally characterized, not improved.
- Lines beginning with `#` between metadata and URL are ignored; lines beginning with `#EXTINF` replace any pending metadata record; a dangling `#EXTINF` produces no stream and no error.
- The optimized parser does not apply the normal parser's global `:-1` removal or single-quote-to-double-quote normalization. This plan preserves the corrected optimized path; it does not claim equivalence with `makeInterfaceFromM3UOriginal`.
- Existing fixture `src/internal/m3u-parser/test_list_1.m3u` contains four LF records, one intervening comment, blank lines, one whitespace-only line after a completed record, and a final newline. Existing `TestStream1` exercises only the normal path because the fixture is 586 bytes and does not assert exact values. The new compatibility corpus is inline so CRLF and unterminated-final-line bytes are unambiguous.
- No benchmarks or `testing.B.Loop` calls currently exist. `benchstat` is not installed and `golang.org/x/perf` is not in `go.mod`; the pinned `go run` command below was verified not to alter module files.

```go
func serializeArgon2IDHash(salt, key []byte) string {
	encoded := make([]byte, 0,
		len("$argon2id$v=19$m=19456,t=2,p=1$$")+
			base64.RawStdEncoding.EncodedLen(len(salt))+
			base64.RawStdEncoding.EncodedLen(len(key)),
	)
	encoded = append(encoded, "$argon2id$v="...)
	encoded = strconv.AppendInt(encoded, int64(argon2.Version), 10)
	encoded = append(encoded, "$m="...)
	encoded = strconv.AppendInt(encoded, int64(passwordMemory), 10)
	encoded = append(encoded, ",t="...)
	encoded = strconv.AppendInt(encoded, int64(passwordIterations), 10)
	encoded = append(encoded, ",p="...)
	encoded = strconv.AppendInt(encoded, int64(passwordParallelism), 10)
	encoded = append(encoded, '$')
	encoded = base64.RawStdEncoding.AppendEncode(encoded, salt)
	encoded = append(encoded, '$')
	encoded = base64.RawStdEncoding.AppendEncode(encoded, key)
	return string(encoded)
}
```

The capacity expression is an allocation hint only; all PHC numeric fields still come from the existing constants and `argon2.Version`. Raw unpadded base64 and field order remain exact.

```go
func TestMakeInterfaceFromM3UOptimizedLinePolicies(t *testing.T) {
```

```go
// MakeInterfaceFromM3UOptimized : Optimized version for large M3U files
func MakeInterfaceFromM3UOptimized(byteStream []byte) (allChannels []interface{}, err error) {
	if bytes.Contains(byteStream, []byte("#EXT-X-TARGETDURATION")) || bytes.Contains(byteStream, []byte("#EXT-X-MEDIA-SEQUENCE")) {
		return nil, errors.New("Invalid M3U file, an extended M3U file is required.")
	}
	if !bytes.Contains(byteStream, []byte("#EXTM3U")) {
		return nil, errors.New("Invalid M3U file, an extended M3U file is required.")
	}

	scanner := bufio.NewScanner(bytes.NewReader(byteStream))
	scanner.Buffer(make([]byte, 0, 64*1024), 1024*1024)

	allChannels = make([]interface{}, 0, bytes.Count(byteStream, []byte("#EXTINF")))
	var extinfLine string
	var isInChannel bool

	for scanner.Scan() {
		line := scanner.Text()
		if len(line) == 0 {
			continue
		}
		if strings.HasPrefix(line, "#EXTINF") {
			extinfLine = line
			isInChannel = true
			continue
		}
		if strings.HasPrefix(line, "#") {
			continue
		}
		if !isInChannel {
			continue
		}

		if stream := parseMetaDataOptimized(extinfLine, line); len(stream) > 0 {
			allChannels = append(allChannels, stream)
		}
		extinfLine = ""
		isInChannel = false
	}

	if err := scanner.Err(); err != nil {
		return nil, err
	}
	return allChannels, nil
}

// parseMetaDataOptimized : Optimized metadata parsing
func parseMetaDataOptimized(extinfLine, url string) map[string]string {
	// The removed metadata rescan used Scanner's default token limit and
	// silently dropped records at or above that boundary.
	if len(extinfLine) >= bufio.MaxScanTokenSize || len(url) >= bufio.MaxScanTokenSize {
		return nil
	}

	stream := make(map[string]string, 12)
	stream["url"] = strings.TrimSpace(url)

	var value strings.Builder
	streamParameter := parameterRegex.FindAllString(extinfLine, -1)
	for _, p := range streamParameter {
		extinfLine = strings.Replace(extinfLine, p, "", 1)
		cleanParam := quoteReplacer.Replace(p)
		if paramParts := strings.SplitN(cleanParam, "=", 2); len(paramParts) == 2 {
			key, val := paramParts[0], paramParts[1]
			if strings.Contains(key, "tvg") {
				stream[strings.ToLower(key)] = val
			} else {
				stream[key] = val
			}
			if !strings.Contains(val, "://") && len(val) > 0 {
				value.WriteString(val)
				value.WriteByte(' ')
			}
		}
	}

	var channelName string
	if nameMatches := channelNameRegex.FindStringSubmatch(extinfLine); len(nameMatches) > 1 {
		channelName = nameMatches[1]
		channelName = commaReplacer.Replace(channelName)
		channelName = strings.TrimSpace(channelName)
	}
	if len(channelName) == 0 {
		if tvgName, ok := stream["tvg-name"]; ok {
			channelName = tvgName
		}
	}
	if len(channelName) == 0 {
		return nil
	}
	if tvgID := stream["tvg-id"]; tvgID == "" || tvgID == "(no tvg-id)" {
		hash := md5.Sum([]byte(stream["url"]))
		stream["tvg-id"] = fmt.Sprintf("threadfin-%x", hash)
	}

	stream["name"] = strings.TrimSpace(channelName)
	value.WriteString(channelName)
	stream["_values"] = value.String()
	if tvgName, ok := stream["tvg-name"]; ok && len(tvgName) > 0 {
		stream["_uuid.key"] = "tvg-name"
		stream["_uuid.value"] = tvgName
	}
	return stream
}
```
