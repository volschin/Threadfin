# Go 1.27 Confined Archive Extraction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace both ZIP extractors with one Go 1.27 `os.Root`-confined implementation while preserving caller publication behavior, overwrite semantics, and native permission handling.

**Architecture:** Add `threadfin/src/internal/archive` with one exported path-based extractor. It cleans canonical ZIP slash paths with `path.Clean`, classifies non-local paths before `filepath.Localize`, and performs all entry-relative filesystem operations through one `*os.Root`; backup restore and updater extraction migrate in separate commits. Tests use native temporary directories because AVFS cannot model `os.Root`, symlinks, Unix modes, Windows junctions, or reparse-point behavior.

**Tech Stack:** Go 1.27.0, `archive/zip`, `os.Root`, `path`, `path/filepath`, `io`, `errors`, Go tests, GitHub Actions

**Spec:** `docs/superpowers/specs/2026-08-26-go-1.27-modernization-design.md`

## Global Constraints

- Keep the module at exactly `go 1.27.0`; do not change `go.mod`, `go.sum`, or `vendor/`.
- Modify first-party code only and add no dependency.
- Preserve public APIs, persisted formats, backup contents, updater signature verification, and release targets: Linux (`amd64`, `arm64`, `arm`), FreeBSD (`amd64`, `arm`), macOS (`amd64`, `arm64`), and Windows (`amd64`).
- The only new exported interface is `func ExtractZIP(archivePath, targetDir string) error` in package `threadfin/src/internal/archive`.
- Open the ZIP before creating the target, preserving the current behavior that an unreadable archive does not create the target.
- Create an absent target with `0755`, then validate/open it with `os.OpenRoot`; `targetDir` is caller-selected and trusted. `os.OpenRoot` follows a symlink in the root name, so this change does not secure selection of an attacker-controlled target directory.
- Clean each ZIP name with `path.Clean`; reject slash-absolute paths and cleaned `..` traversal, classify native non-local names with `filepath.IsLocal`, then call `filepath.Localize` and reject conversion failures.
- Backslashes remain literal filename characters on Unix. On Windows, `filepath.Localize` rejects a canonical ZIP name containing `\`; drive-qualified and reserved-device names are non-local.
- After `os.OpenRoot(targetDir)` succeeds, create parents, directories, files, and failed-entry cleanup only through `*os.Root`.
- Create omitted parents with `0755`. Create explicit ZIP directories and new files with `zip.File.Mode().Perm()`. Native umask may remove requested bits; tests compare against reference objects created under the same umask.
- Open files with `os.O_WRONLY|os.O_CREATE|os.O_TRUNC`. A successful overwrite preserves an existing regular file's mode because `perm` is ignored for an existing file.
- If copying or closing an entry fails, remove that entry path through `Root.Remove`. If the entry overwrote an existing file, the old contents are not restored and the failed destination is removed. Earlier successful entries and the extraction root remain.
- Do not create symlinks from ZIP metadata: a ZIP symlink entry remains a regular file containing the entry data, matching current behavior.
- Existing symlinks are followed only when their resolved path remains inside the root. The extractor rejects absolute or escaping symlink targets, but intentionally permits in-root symlink aliases.
- Do not describe `os.Root` as a complete filesystem sandbox. Go 1.27 documents that it does not block filesystem boundaries, Linux bind mounts, `/proc`, Unix device files, or writes through pre-existing hard links. This package confines path resolution only.
- The implementation does not call `Root.Chmod`, `Root.Chown`, or `Root.Chtimes`; therefore it does not introduce the Unix final-component race documented for those methods.
- Close the current destination and source immediately after each copy. Preserve error identity with `%w` and `errors.Join`; entry failures identify the original ZIP name and operation.
- The shared extractor owns only current-entry cleanup. Backup restore keeps its existing direct-to-config behavior and current `tmpRestore` lifecycle. Updater code keeps target-wide cleanup of the verified download and unpublished extraction directory.
- Do not route the package through `github.com/avfs/avfs`; AVFS remains used only by `bufferVFS` in `src/buffer.go`.
- Native Linux and macOS tests cover Unix permissions and symlinks. Native Windows tests cover `filepath` policy and junctions. Cross-compilation proves compilation only.
- The concurrent symlink test is a stress regression test, not proof of race freedom; deterministic pre-existing-link tests and the standard library's documented `os.Root` contract are the primary boundary evidence.
- Every implementation task runs `go test -count=1 -mod=vendor ./...`, `go vet -mod=vendor ./...`, and `git diff --check` before completion.

There is no `Root.MkdirTemp`, `Root.CreateTemp`, or `Root.ReadDir` method in Go 1.27. This plan uses only `Close`, `MkdirAll`, `OpenFile`, and `Remove`. It deliberately does not use the redundant pattern `local, _ := filepath.Localize(name); filepath.IsLocal(local)`: the Go 1.27 `Localize` contract already guarantees that a successful result is local, so the non-local classification occurs before conversion.

package archive

import (
	"archive/zip"
	"encoding/binary"
	"errors"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"strings"
	"testing"

type testEntry struct {
	name string
	body []byte
	mode fs.FileMode
}

func writeTestZIP(t *testing.T, archivePath string, entries ...testEntry) {
	t.Helper()
	archiveFile, err := os.Create(archivePath)
	if err != nil {
		t.Fatal(err)
	}
	archiveWriter := zip.NewWriter(archiveFile)
	for _, item := range entries {
		header := &zip.FileHeader{Name: item.name, Method: zip.Store}
		header.SetMode(item.mode)
		entryWriter, err := archiveWriter.CreateHeader(header)
		if err != nil {
			t.Fatal(err)
		}
		if _, err := entryWriter.Write(item.body); err != nil {
			t.Fatal(err)
		}
	}
	if err := errors.Join(archiveWriter.Close(), archiveFile.Close()); err != nil {
		t.Fatal(err)
	}
}

func corruptFirstEntryData(t *testing.T, archivePath string) {
	t.Helper()
	data, err := os.ReadFile(archivePath)
	if err != nil {
		t.Fatal(err)
	}
	if len(data) < 30 || string(data[:4]) != "PK\x03\x04" {
		t.Fatal("archive does not begin with a local ZIP header")
	}
	nameLength := int(binary.LittleEndian.Uint16(data[26:28]))
	extraLength := int(binary.LittleEndian.Uint16(data[28:30]))
	dataOffset := 30 + nameLength + extraLength
	if dataOffset >= len(data) {
		t.Fatal("archive has no entry data to corrupt")
	}
	data[dataOffset] ^= 0xff
	if err := os.WriteFile(archivePath, data, 0600); err != nil {
		t.Fatal(err)
	}
}

func TestExtractZIPRejectsTraversalAndSlashAbsolutePaths(t *testing.T) {
	testCases := []struct {
		name       string
		entry      string
		wantReason string
	}{
		{name: "parent", entry: "../escaped.txt", wantReason: "traverses outside target directory"},
		{name: "cleaned parent", entry: "safe/../../escaped.txt", wantReason: "traverses outside target directory"},
		{name: "slash absolute", entry: "/absolute.txt", wantReason: "is absolute"},
	}
	for _, testCase := range testCases {
		t.Run(testCase.name, func(t *testing.T) {
			root := t.TempDir()
			archivePath := filepath.Join(root, "malicious.zip")
			target := filepath.Join(root, "target")
			writeTestZIP(t, archivePath, testEntry{name: testCase.entry, body: []byte("escaped"), mode: 0644})

			err := ExtractZIP(archivePath, target)
			if err == nil {
				t.Fatalf("ExtractZIP accepted %q", testCase.entry)
			}
			if !strings.Contains(err.Error(), testCase.entry) || !strings.Contains(err.Error(), testCase.wantReason) {
				t.Fatalf("error %q does not identify %q and reason %q", err, testCase.entry, testCase.wantReason)

			if readErr != nil {
				t.Fatal(readErr)
			}
			if len(entries) != 0 {
				t.Fatalf("rejected archive created entries: %v", entries)
			}
		})
	}
}

package archive

import (
	"archive/zip"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path"
	"path/filepath"
	"strings"
)

// ExtractZIP extracts archivePath into targetDir without permitting archive
// path traversal or symbolic-link resolution outside targetDir. os.Root does
// not prevent filesystem-boundary traversal, Linux bind mounts, special
// filesystems, device-file access, or writes through pre-existing hard links.
func ExtractZIP(archivePath, targetDir string) (err error) {
	reader, err := zip.OpenReader(archivePath)
	if err != nil {
		return fmt.Errorf("open ZIP archive %q: %w", archivePath, err)
	}
	defer func() {
		err = errors.Join(err, wrapOperationError("close ZIP archive", reader.Close()))
	}()

	if err := os.MkdirAll(targetDir, 0755); err != nil {
		return fmt.Errorf("create ZIP target %q: %w", targetDir, err)
	}
	targetRoot, err := os.OpenRoot(targetDir)
	if err != nil {
		return fmt.Errorf("open ZIP target %q: %w", targetDir, err)
	}
	defer func() {
		err = errors.Join(err, wrapOperationError("close ZIP target", targetRoot.Close()))
	}()

	for _, entry := range reader.File {
		if err := extractEntry(targetRoot, entry); err != nil {
			return err
		}
	}
	return nil
}

func extractEntry(targetRoot *os.Root, entry *zip.File) error {
	localName, err := localArchiveName(entry.Name)
	if err != nil {
		return err
	}
	if entry.FileInfo().IsDir() {
		parent := filepath.Dir(localName)
		if parent != "." {
			if err := targetRoot.MkdirAll(parent, 0755); err != nil {
				return fmt.Errorf("archive entry %q: create parent directories: %w", entry.Name, err)
			}
		}
		if err := targetRoot.MkdirAll(localName, entry.Mode().Perm()); err != nil {
			return fmt.Errorf("archive entry %q: create directory: %w", entry.Name, err)
		}
		return nil
	}
	if err := targetRoot.MkdirAll(filepath.Dir(localName), 0755); err != nil {
		return fmt.Errorf("archive entry %q: create parent directories: %w", entry.Name, err)
	}

	source, err := entry.Open()
	if err != nil {
		return fmt.Errorf("archive entry %q: open source: %w", entry.Name, err)
	}
	destination, err := targetRoot.OpenFile(localName, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, entry.Mode().Perm())
	if err != nil {
		return errors.Join(
			fmt.Errorf("archive entry %q: open destination: %w", entry.Name, err),
			wrapOperationError(fmt.Sprintf("archive entry %q: close source", entry.Name), source.Close()),
		)
	}

	operationErr := copyAndClose(destination, source)
	if operationErr == nil {
		return nil
	}
	removeErr := targetRoot.Remove(localName)
	if removeErr != nil && !errors.Is(removeErr, fs.ErrNotExist) {
		operationErr = errors.Join(operationErr, fmt.Errorf("remove incomplete archive entry %q: %w", entry.Name, removeErr))
	}
	return fmt.Errorf("archive entry %q: %w", entry.Name, operationErr)
}

func copyAndClose(destination io.WriteCloser, source io.ReadCloser) error {
	_, copyErr := io.Copy(destination, source)
	return errors.Join(
		wrapOperationError("copy entry data", copyErr),
		wrapOperationError("close destination", destination.Close()),
		wrapOperationError("close source", source.Close()),
	)
}

func localArchiveName(name string) (string, error) {
	cleanName := path.Clean(name)
	if path.IsAbs(cleanName) {
		return "", fmt.Errorf("archive entry %q is absolute", name)
	}
	if cleanName == ".." || strings.HasPrefix(cleanName, "../") {
		return "", fmt.Errorf("archive entry %q traverses outside target directory", name)
	}
	if !filepath.IsLocal(cleanName) {
		return "", fmt.Errorf("archive entry %q is not local", name)
	}
	localName, err := filepath.Localize(cleanName)
	if err != nil {
		return "", fmt.Errorf("archive entry %q is invalid on this platform: %w", name, err)
	}
	return localName, nil
}

func wrapOperationError(operation string, err error) error {
	if err == nil {
		return nil
	}
	return fmt.Errorf("%s: %w", operation, err)
}

## Native Verification Boundary

- Linux-native tests are authoritative for this repository's main Unix path, permissions, pre-existing relative symlink escape, in-root symlink following, and concurrent replacement stress.
- macOS-native CI reruns the non-Windows tests against Darwin filesystem semantics.
- Windows-native CI is authoritative for backslash conversion failure, drive/reserved-name locality, and mount-point/junction containment. The junction setup fails CI rather than silently skipping there.
- FreeBSD is compile-only in this repository. Go 1.27 selects its descriptor-relative Unix `os.Root` implementation, but this plan does not claim native FreeBSD filesystem execution.
- Vendor-specific Windows reparse tags are an explicit test limitation. The extractor relies on Go 1.27's `os.Root` implementation to reject escaping name-surrogate reparse targets and does not simulate unsupported tags with AVFS.
